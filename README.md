# Useful Quick Scripts

Kho lưu trữ các script tiện ích nhanh (Browser Console, CLI, Automation, Web Scraping, UI Cloning,...).

## Danh mục

### 1. Web & UI Cloners
- [`clone-ui.js`](./clone-ui.js): Export toàn bộ trang web hiện tại thành một file HTML duy nhất (gộp inline CSS, inline/fetch `@import`, giữ font, loại bỏ JS/tracking thừa). Chạy trực tiếp trên Console của trình duyệt.
